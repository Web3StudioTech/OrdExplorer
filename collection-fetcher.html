📋 HOW TO USE THE DOWNLOADED FILE

Step 1: Click "Start Fetching" and wait for it to complete (may take several minutes for thousands of collections)

Step 2: Click "Download collections.json" — save the file

Step 3: Add collections.json to your GitHub repo root:
OrdExplorer/collections.json

Step 4: The explorer (index.html) will automatically load it via fetch('./collections.json') before trying BestInSlot live.

Step 5: Re-run this fetcher monthly to keep the file updated. Just replace the old collections.json in your repo.

Backup logic in explorer:
collections.json (local) → BestInSlot live API → hardcoded fallback
